How does this work?

      
When you press Run program, Panackelty checks your code and compiles it into bytecode: instructions for the Panackelty virtual machine (VM). The VM then executes those instructions and displays the output above.

      
      
Compilation and execution happen on your device; your source code is not sent to a server. Each run starts fresh.

    

    
What can I run here?
      
Complete programs using exact numbers, types, pure functions, collections and supported standard-library operations. Compiler errors appear above, with source positions where available.

      
Programs cannot access your device files, start processes or use networking. Runtime file writes and typed native host services are unavailable; standard input is empty. This is not a persistent REPL.

      
Limits: 32 KiB UTF-8 source and output, a 15-second foreground timeout and 256 MiB of linear memory per VM instance. The browser uses additional memory. Background timers may be delayed; Stop ends the worker.
